GiseUGC is the marketing and portfolio site I built for Gisela Saldarriaga, a UGC creator who needed her video work to sell itself. The whole site is designed around one constraint: video is the product, so video delivery has to be flawless on any connection.

## What it does

- Serves a video catalog through **HLS adaptive streaming** with an MP4 fallback, delivered from **Cloudflare R2** so origin bandwidth never becomes a cost problem
- Runs fully **bilingual** — Spanish at `/`, English at `/en/` — with content-managed strings and layouts tolerant to ±35% text-length variance
- Generates data-driven landing pages for services, verticals, and resources
- Uses motion as a design pillar: GSAP entrance choreography, Lenis smooth scrolling, and a three.js hero atmosphere

## Build notes

The site is a static React + Vite build with per-route HTML entries, so it ships fast without a server. A prebuild pipeline regenerates the video catalog from a media manifest — adding a new reel is a manifest edit, not a code change.

The interesting problems were operational, not visual: getting adaptive playback to behave across devices, keeping R2 delivery cheap and cache-friendly, and structuring bilingual content so neither language feels like the translation.

## Status

In production and actively maintained — recent work includes a testimonials redesign, SEO passes, and adaptive playback refinements.
